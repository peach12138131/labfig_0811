### 1.3 两条建模约定（重要）

**① 时间轴**：按 `rule.md`，**令 t=0 对应实验的 6h**，即拟合时间点为
t' = [0, 18, 42, 66] h。6h 的实测均值直接作为初始量 N₀，
**不作为自由参数**参与拟合。因此每条曲线用 3 个有效时间点去定 2 个参数（r、K）。

**② 尺度**：按 `step1.png`，方程中的 N、K、N₀ **单位都是 log₁₀ CFU**，
即直接在对数尺度上做 logistic / gLV 拟合，不还原成绝对菌数。
这一约定的两个后果必须记住：

- K 是「log₁₀ 值的平台高度」，不是真实承载容量；
- **α 乘的是对数值，因此不具备接种量尺度不变性** —— 同一对菌在不同接种量下拟合出的
  α 不能互换使用。这一点在第 6 节会成为决定性的问题。

## 2. 计算公式

### 2.1 第一步：单培养 logistic（估 r、K）

微分形式与解析解：

$$\frac{dN_i}{dt} = r_i N_i\left(1 - \frac{N_i}{K_i}\right)
\qquad\Longrightarrow\qquad
N_i(t) = \frac{K_i}{1 + \left(\frac{K_i - N_0}{N_0}\right)e^{-r_i t}}$$

| 参数 | 含义 | 单位 |
|---|---|---|
| $r_i$ | 物种 i 的内禀增长率 | h⁻¹ |
| $K_i$ | 物种 i 的承载容量 | log₁₀ CFU |
| $N_0$ | 初始量，直接取 t=0（实验 6h）实测均值 | log₁₀ CFU |

用非线性最小二乘（`scipy.optimize.curve_fit`，信赖域反射法）对 4 个时间点的**均值**
最小化 $\sum_t (N_{obs}(t) - N_{pred}(t))^2$，$N_0$ 固定。

### 2.2 第二步：双培养 gLV（估 α）

固定第一步的 $r_i, K_i$，只拟合两个互作系数：

$$\frac{dN_1}{dt} = r_1 N_1\left(1 - \frac{N_1 + \alpha_{12}N_2}{K_1}\right)
\qquad
\frac{dN_2}{dt} = r_2 N_2\left(1 - \frac{N_2 + \alpha_{21}N_1}{K_2}\right)$$

方程无解析解，用 `solve_ivp`（RK45）数值积分，`least_squares` 对
$(\alpha_{12}, \alpha_{21})$ 最小化两物种残差的拼接向量，初值 $(0,0)$，边界 $\pm 5$。

**α 的符号规则**（step3.png）：

$$\alpha_{ij} > 0 \Rightarrow \text{物种 j 抑制物种 i（竞争）}$$
$$\alpha_{ij} < 0 \Rightarrow \text{物种 j 促进物种 i（互利）}$$
$$\alpha_{ij} = 0 \Rightarrow \text{无影响（中性）}$$

本报告取 $|\alpha| < 0.05$ 判为中性。

### 2.3 第三步：三培养预测（不拟合新参数）

把前两步的全部参数代入三物种方程，直接数值积分：

$$\frac{dN_i}{dt} = r_i N_i\left(1 - \frac{N_i + \sum_{j \neq i}\alpha_{ij}N_j}{K_i}\right)
,\quad i = 1,2,3$$

初值 $N_i(0)$ 取**三培养体系中**物种 i 的 6h 实测均值。
**这一步没有任何自由参数** —— 预测与实测的偏离完全反映模型的外推能力。

### 2.4 拟合优度

$$R^2 = 1 - \frac{\sum(y_{obs}-y_{pred})^2}{\sum(y_{obs}-\bar{y}_{obs})^2}
\qquad
RMSE = \sqrt{\frac{1}{n}\sum(y_{obs}-y_{pred})^2}$$

$$MAE = \frac{1}{n}\sum|y_{obs}-y_{pred}|
\qquad
bias = \frac{1}{n}\sum(y_{obs}-y_{pred})$$

注意 $R^2$ 在**预测**（而非拟合）场景下可以为负 —— 那表示模型比「直接用实测均值」还差。

## 3. 完整手算示例（662 / L43）

以下每一步的中间数字全部写出，可用计算器逐步复核。

### 3.1 原始复孔 → 均值与标准差

`662` 文件中 **D1 单培养、6h** 的 6 个复孔原始值：

```
4.93, 4.90, 5.00, 4.56, 4.20, 4.78
```

均值：

$$\bar{N} = \frac{4.93 + 4.90 + 5.00 + 4.56 + 4.20 + 4.78}{6}
= \frac{28.37}{6} = \mathbf{4.7283}$$

样本标准差（ddof=1）：

$$SD = \sqrt{\frac{(4.93-4.7283)^2 + (4.90-4.7283)^2 + (5.00-4.7283)^2 + (4.56-4.7283)^2 + (4.20-4.7283)^2 + (4.78-4.7283)^2}{6-1}}
= \sqrt{\frac{0.454083}{5}}
= \sqrt{0.090817} = \mathbf{0.3014}$$

这个均值就是第一步的初始量：$N_0 = 4.7283$（log₁₀ CFU）。

### 3.2 第一步：拟合 r 与 K

对 4 个时间点的均值做非线性最小二乘，得

$$r_{D1} = \mathbf{0.0640}\ \text{h}^{-1}, \qquad
K_{D1} = \mathbf{7.2081}\ \log_{10}\text{CFU}$$

**代入验证 24h（即 t' = 18 h）**：

$$\frac{K - N_0}{N_0} = \frac{7.2081 - 4.7283}{4.7283}
= \frac{2.4797}{4.7283} = 0.52444$$

$$e^{-r t} = e^{-0.0640 \times 18} = e^{-1.1526} = 0.31581$$

$$N(18) = \frac{7.2081}{1 + 0.52444 \times 0.31581}
= \frac{7.2081}{1 + 0.16563}
= \frac{7.2081}{1.16563} = \mathbf{6.1839}$$

实测 24h 均值 = 6.1317，**残差 = 6.1317 − 6.1839 = -0.0522**。

### 3.3 第二步：拟合 α

固定上面的 $r, K$，对 `D1-L43` 双培养数值积分并最小化残差，得

$$\alpha_{D1 \leftarrow L43} = \mathbf{-0.3471}
\quad(<0，L43 \text{ 促进 D1})$$
$$\alpha_{L43 \leftarrow D1} = \mathbf{+0.1024}
\quad(>0，\text{D1 }抑制\ L43)$$

对补充数据（D1-D6 双培养）同样处理，得
$\alpha_{D1 \leftarrow D6} = \mathbf{+1.8076}$。

### 3.4 第三步：代入三菌方程

`D1-D6-L43` 三培养在 6h（t=0）的实测均值：

$$N_{D1}(0) = 4.8850,\quad N_{D6}(0) = 5.2683,\quad N_{L43}(0) = 1.0000$$

**方案 A（α(D1,D6) 取自补充数据）** —— 计算 D1 在 t=0 的瞬时变化率：

$$N_{D1} + \alpha_{D1\leftarrow D6}N_{D6} + \alpha_{D1\leftarrow L43}N_{L43}
= 4.8850 + (+1.8076)(5.2683) + (-0.3471)(1.0000)$$
$$= 4.8850 +9.5230 -0.3471 = \mathbf{14.0609}$$

$$\frac{dN_{D1}}{dt}\bigg|_{t=0}
= 0.0640 \times 4.8850 \times \left(1 - \frac{14.0609}{7.2081}\right)
= 0.3128 \times (1 - 1.9507)
= \mathbf{-0.2974}$$

括号里的 $14.0609 / 7.2081 = 1.9507 > 1$，**导数为负，模型预测 D1 从一开始就下降**；
而实测 D1 是从 4.89 增长到 72h 的 7.82。方案 A 在这里就已经走反了方向。

**方案 B（α(D1,D6) = 0）** —— 同一时刻：

$$N_{D1} + 0 \times N_{D6} + (-0.3471)(1.0000)
= 4.8850 -0.3471 = \mathbf{4.5379}$$

$$\frac{dN_{D1}}{dt}\bigg|_{t=0}
= 0.0640 \times 4.8850 \times \left(1 - \frac{4.5379}{7.2081}\right)
= 0.3128 \times (1 - 0.6296)
= \mathbf{+0.1159}$$

导数为正，D1 增长 —— 与实测方向一致。

**两个方案的差别只在 $\alpha_{D1\leftarrow D6}$ 这一个数**：它把括号里的项从
4.5379 抬到了 14.0609，越过了 $K = 7.2081$，导致整个符号翻转。
第 6 节给出这个差异在全部 8 份数据上的后果。

若曲线尚未进入平台期，r 与 K 高度相关、可以互相补偿：

- **662 / L1091**（K = 15.00）：K hit the upper bound 15.0 - curve has not plateaued, K is not identifiable from 4 points
- **662 / L1253**（K = 5.79）：K = 5.79 is 2.6x the largest observed value - far extrapolation, K poorly identified
- **662 / L2182**（K = 15.00）：K hit the upper bound 15.0 - curve has not plateaued, K is not identifiable from 4 points

这 3 组都属于 662（L 菌 2 log 接种）。它们的 K 是**外推**出来的，
后续用到这些 K 的 α 与三菌预测都继承了这份不确定性。

## 7. 结论

### 7.1 D 菌与 L 菌之间是什么关系

| 方向 | 662（L 2 log） | 664（L 4 log） |
|---|---|---|
| L → D1 | **促进**（α = -0.416 ~ -0.347） | **促进**（α = -0.233 ~ -0.204） |
| L → D6 | **抑制**（α ≈ +0.30 ~ +0.37） | **中性**（\|α\| < 0.05） |
| D1 → L | 抑制（α 多为正，L1091/L2182 尤强） | 中性 ~ 弱 |
| D6 → L | 弱促进 ~ 中性 | **促进**（α ≈ −0.05 ~ −0.13） |

两条最稳的结论：

1. **4 株 L 菌都促进 D1**，8 个组合无一例外，且不受接种量影响。
2. **D1 与 D6 对 L 菌的响应方向相反**：L 菌抑制 D6（仅在低接种量下显现），却促进 D1。

### 7.2 接种量（2 log vs 4 log）的影响

L 菌接种量从 2 log 提到 4 log 后，互作强度**普遍减弱并向中性靠拢**：
α(D6←L) 从 +0.3 降到 0，α(D1←L) 的促进作用从约 −0.38 减到约 −0.22。
但要注意，这既可能是真实的生态学效应，也可能来自 662 组 L 菌大量处于检出限
（见 8.4），两者用现有数据分不开。

### 7.3 三菌行为能否由双菌参数预测

**能，但前提是不引入 α(D1↔D6)。**

- 在方案 B 下，只用单培养的 r、K 与双培养的 4 个 α，就能把三菌体系中 D1、D6 的
  轨迹预测到 R² = 0.808 ~ 0.984（RMSE 约 0.2–0.6 log），
  **不拟合任何新参数**。这说明 gLV 框架对这个体系是适用的，双菌互作确实具有可加性。
- **L 菌的预测明显更差**（R² = -0.026 ~ 0.918），
  且误差方向随接种量翻转：662 下 bias（实测−预测）为
  +0.304 ~ +0.407（模型**低估** L 菌），
  664 下为 -0.859 ~ -0.266（模型**高估** L 菌）。
  这不是一个方向上的系统偏差，而是模型在两种接种量下**朝相反方向出错** ——
  提示 L 菌的响应不能用一组与接种量无关的 α 描述（呼应 8.2），
  也可能是 662 下 L 菌的 r、K 本身就不可靠（见 8.4）。

**方案 A 不成立。** 严格按 `rule.md` 用补充数据拟合的 α(D1↔D6) 代入后，
D1、D6 的预测 R² 为 −4.5 ~ −14.9，方向都是错的。第 5.3 节的尺度诊断给出了原因：
补充数据的实验尺度与主实验相差约 3.7 个 log，其 α 无法搬运到主实验的三菌体系。

**如果需要 α(D1↔D6)，正确的做法是在与主实验相同的接种量（6 log）下补做一次
D1-D6 双培养。** 现有的补充数据无法替代它。

## 8. 局限性

**8.1 补充数据的尺度不匹配（最关键）**
补充数据的 D1/D6 起始量约 1.1–1.3 log，主实验约 4.7–5.0 log，相差约 3.7 个 log；
把它当单培养拟合出的 K 只有主实验的 1/3（`scale_diagnostic.csv`）。
由此得到的 α(D1↔D6) 无法直接用于主实验的三菌预测。本报告两套都算并如实呈现，
未替使用者删除方案 A。

**8.2 log₁₀ 尺度下的 α 不具尺度不变性**
按 `step1.png` 的约定，方程中的 N 就是 log₁₀ 值，因此 α·N 这一项随实验的对数量级线性放大。
同一对菌在 662 与 664 下拟合出的 α 明显不同（5.1 节解读 ④），是同一问题在主数据内部的表现。
跨接种量比较 α 的绝对大小时须谨慎。

**8.3 自由度极低**
每条曲线只有 4 个时间点，且 6h 被固定为 N₀，实际只有 3 个点去定 r 和 K 两个参数，
无残差自由度可言，也无法给出参数的置信区间。报告中的 R² 只反映曲线是否穿过这几个点。

**8.4 K 不可辨识（3 组）**
662/L1091、662/L2182 的 K 顶到了搜索上界 15.0，
662/L1253 的 K 是最大观测值的 2.6 倍 —— 这些曲线到 72h 仍未进入平台期，K 纯靠外推。
它们全部属于 662 组（L 菌 2 log 接种），其中多个时间点的实测值就是检出限 1.0（左删失），
N₀ 与 K 都不可靠，依赖它们的 α 与 L 菌预测同样不可靠。

**8.5 α 按文件分别拟合**
同一菌对在 662 与 664 下各拟合一次，得到两个不同的 α。这是为了让每个文件自成体系
（三菌预测也按文件做），但也意味着 α 不是一个统一估计，不能直接跨接种量引用。

**8.6 只比较均值**
拟合与预测都针对各时间点的均值（n=6，补充数据 n=3），未把复孔离散度纳入加权，
也未对预测与实测做统计显著性检验 —— 本任务的目标是机理模型的预测能力，
而非组间差异检验。`triple_prediction.csv` 中保留了 `obs_sd` 供需要时使用。

**8.7 每条预测曲线只有 4 个比较点**
第 6 节的 R² 都建立在 4 个时间点（其中 t=0 被固定为初值，残差恒为 0）之上，
实际只有 3 个独立的比较点。R² 的绝对数值不宜过度解读，
方案 A 与 B 之间**量级上的**差异（−14.9 vs +0.98）才是可靠的结论。
