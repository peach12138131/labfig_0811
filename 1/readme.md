## 2. 数据质量与前提说明

**(a) 数据已是 log₁₀ 值。** step2.png 要求「CFU 计数通常需先做 log10 转换」——
原始 xlsx 记录的已经是 log₁₀ CFU/cm²（单菌 D 菌约 5–9，L 菌 1–7），因此本分析
**不再做二次对数变换**，直接在 log 尺度上建模。

**(b) 检出限左删失。** fig1 有 14 个 cell、fig3 有 12 个 cell
的 6 个复孔数值完全相同（多为 1.0），集中出现在 2 log 接种量的 L 菌早期时间点 ——
这是计数达到检出限下限的表现，属**左删失数据**，不是真实的"零变异"。
对这些 cell：Shapiro-Wilk 与 Levene 无法计算（记为 `—`）；
两组都完全相同时不做检验（记 `identical_no_variation`）；
只有一组是常量时自动改用 Mann-Whitney U。**这些位置的统计功效极低，结论应谨慎。**

**(c) 疑似录入重复。** 以下 3 组的后 3 个复孔与前 3 个逐一相同，疑为录入时复制粘贴，
**实际独立重复可能只有 3 而非 6**，会低估标准差、高估显著性：

| 文件 | 体系 | 组合 | 菌株 | 时间 | 6 个复孔 |
|---|---|---|---|---|---|
| fig1 | Dual | D1-L43 | D1 | 24h | 6.18, 6.28, 6.32, 6.18, 6.28, 6.32 |
| fig1 | Dual | D1-L1091 | D1 | 24h | 6.36, 6.3, 6.38, 6.36, 6.3, 6.38 |
| fig1 | Dual | D1-L1253 | D1 | 24h | 6.38, 6.28, 6.43, 6.38, 6.28, 6.43 |

建议核对原始实验记录；本报告未删除这些数据，仅在此标注。

## 3. 计算公式

### 3.1 描述统计

- 均值：$\bar{x} = \frac{1}{n}\sum_{i} x_i$
- 样本标准差（ddof = 1）：$s = \sqrt{\frac{\sum_{i}(x_i - \bar{x})^2}{n-1}}$
- 标准误：$\text{SEM} = s / \sqrt{n}$
- 变异系数：$\text{CV}(\%) = 100 \cdot s / \bar{x}$
- $\Delta = \text{多菌均值} - \text{同文件同菌同时间点的单菌均值}$

### 3.2 前提检查

- **Shapiro-Wilk 正态性**：$W = \frac{(\sum_{i} a_i x_{(i)})^2}{\sum_{i}(x_i - \bar{x})^2}$。
  W 越接近 1 越正态；p ≥ 0.05 时不拒绝正态假设。
  本报告对每个 cell（n = 6）各做一次，并对整个 series 的 ANOVA **残差**（n = 72）
  再做一次 —— 后者是判定用的主判据，因为 n = 6 的 Shapiro 功效太低。
- **Levene 方差齐性**（center = median，即 Brown-Forsythe，对偏态更稳健）：
  令 $Z_{ij} = |x_{ij} - \text{median}_i|$，则

$$W = \frac{N-k}{k-1} \cdot \frac{\sum_{i} n_i(\bar{Z}_i - \bar{Z})^2}{\sum_{i}\sum_{j}(Z_{ij} - \bar{Z}_i)^2}$$

  p ≥ 0.05 时认为方差齐。

**方法选择规则**：残差 Shapiro p ≥ 0.05 **且** Levene p ≥ 0.05 → 采信**参数**结果；
否则采信**非参**结果。两条路线都已计算并输出，csv 的 `primary_method` 列标明采信哪一条。

### 3.3 参数路线：双因素 ANOVA（Type II）

模型：`value ~ C(system) × C(time)`，把总变异拆成

$$SS_{\text{total}} = SS_{\text{system}} + SS_{\text{time}} + SS_{\text{system} \times \text{time}} + SS_{\text{residual}}$$

$$F = \frac{SS_{\text{effect}} / df_{\text{effect}}}{SS_{\text{residual}} / df_{\text{residual}}}$$

偏 $\eta^2 = SS_{\text{effect}} / (SS_{\text{effect}} + SS_{\text{residual}})$，衡量该效应解释掉的变异比例
（经验参考：0.01 小、0.06 中、0.14 大）。

**Tukey HSD** 事后比较（把 system × time 合成 12 个水平，做 $\binom{12}{2} = 66$ 对）：

$$q = \frac{\bar{x}_b - \bar{x}_a}{\sqrt{MS_{\text{residual}} / n}}$$

p 由 studentized range 分布给出，**已内含对 66 次比较的族系错误率控制**，无需再校正。

> **读 `stats_posthoc_tukey.csv` 时请注意**：statsmodels 的 studentized range 实现
> 在 p 极小时会下溢并直接返回 `0.0`（本文件中有 1362 / 2112 行如此），
> 最小的非零值是 `1e-4`。这些 `0.0` 应读作「**p < 1e-4**」，不是真的等于 0，
> 也不是本脚本四舍五入造成的（脚本对所有 P 值列均保留完整精度）。
> 需要精确的小 p 值时，请参考 `stats_core_comparisons.csv`（那里的 t 检验 p 值精确到 1e-50 量级）。

### 3.4 非参路线：Kruskal-Wallis + Dunn

- **Kruskal-Wallis**：$H = \frac{12}{N(N+1)} \cdot \sum_{i} n_i\left(\bar{R}_i - \frac{N+1}{2}\right)^2$，近似 $\chi^2(k-1)$
- **Dunn 事后比较**（含并列秩校正）：

$$z_{ij} = \frac{\bar{R}_i - \bar{R}_j}{\sqrt{\left[\frac{N(N+1)}{12} - T\right] \cdot \left(\frac{1}{n_i} + \frac{1}{n_j}\right)}}$$

$$T = \sum_{k} \frac{t_k^3 - t_k}{12(N-1)}$$

  $t_k$ 为第 $k$ 个并列秩组的大小，双侧 $p = 2 \cdot (1 - \Phi(|z|))$，再做 Holm 校正。

### 3.5 核心比较的两两检验

逐对按下列规则选择方法（写在 csv 的 `test_used` 列）：

| 情形 | 方法 |
|---|---|
| 两组都是常量且数值相同 | 不检验（`identical_no_variation`） |
| 任一组非正态（含常量组） | Mann-Whitney U |
| 两组均正态 + Levene p ≥ 0.05 | Student's t |
| 两组均正态 + Levene p < 0.05 | Welch's t |

- **Student's t**：$s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$，$t = \frac{\bar{x}_2 - \bar{x}_1}{s_p\sqrt{1/n_1 + 1/n_2}}$，$df = n_1 + n_2 - 2$
- **Welch's t**：$t = \frac{\bar{x}_2 - \bar{x}_1}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$，

$$df = \frac{(s_1^2/n_1 + s_2^2/n_2)^2}{\frac{(s_1^2/n_1)^2}{n_1-1} + \frac{(s_2^2/n_2)^2}{n_2-1}}$$

  （Welch–Satterthwaite）

- **Mann-Whitney U**：$U = n_1 n_2 + \frac{n_1(n_1+1)}{2} - R_1$，$R_1$ 为组 1 的秩和

**效应量**：t 检验用 $\text{Hedges' } g = d \cdot \left(1 - \frac{3}{4(n_1+n_2)-9}\right)$（n = 6 必须做小样本校正，约 −6%）；
Mann-Whitney 用秩二列相关 $r = \frac{2U}{n_1 n_2} - 1$。

**多重比较**：Holm-Bonferroni，family = 每个 `(文件, partner, 菌株)` 内的 8 个检验
（2 个核心比较 × 4 个时间点）。把 8 个 p 升序排列，第 i 小的乘 (8−i+1)，
取累积最大值保证单调，截断到 1。

**显著性标记**：`***` p < 0.001，`**` p < 0.01，`*` p < 0.05，`n.s.` 不显著（均指校正后的 p）。

## 4. 完整手算示例：fig2 / partner L43 / 菌株 L43 / 48h / 单菌 vs 双菌

选这一组是因为它数值正常（无检出限截断），能完整走完「正态 → 方差齐 → Student t」这条路径。

**原始数据（6 个复孔，单位 log₁₀ CFU/cm²）**

| 组 | r1 | r2 | r3 | r4 | r5 | r6 |
|---|---|---|---|---|---|---|
| A = Single（单菌 L43，48h） | 6.12 | 6.28 | 6.0 | 6.22 | 6.29 | 6.1 |
| B = Dual（D1-L43 中的 L43，48h） | 5.3 | 5.04 | 5.15 | 5.3 | 5.3 | 5.0 |

**第 1 步：均值**

$\bar{x} = \frac{1}{n}\sum x_i$，$n = 6$

- $\bar{x}_A = (6.12 + 6.28 + 6 + 6.22 + 6.29 + 6.1) / 6 = 37.0100 / 6 = \mathbf{6.1683}$
- $\bar{x}_B = (5.3 + 5.04 + 5.15 + 5.3 + 5.3 + 5) / 6 = 31.0900 / 6 = \mathbf{5.1817}$

**第 2 步：样本标准差**

$s = \sqrt{\sum(x_i - \bar{x})^2 / (n-1)}$

- 组 A：$\sum(x_i - \bar{x}_A)^2 = 0.065283$；$s^2_A = 0.065283 / 5 = 0.013057$；$\mathbf{s_A = 0.1143}$
- 组 B：$\sum(x_i - \bar{x}_B)^2 = 0.096083$；$s^2_B = 0.096083 / 5 = 0.019217$；$\mathbf{s_B = 0.1386}$
- $\text{SEM}_A = s_A/\sqrt{6} = 0.0466$；$\text{SEM}_B = 0.0566$

**第 3 步：正态性（Shapiro-Wilk）**

$W = \frac{(\sum a_i x_{(i)})^2}{\sum(x_i - \bar{x})^2}$，$x_{(i)}$ 为升序排列的观测值，$a_i$ 为由期望正态次序统计量导出的常数。

- 组 A：W = 0.9256，p = 0.5464 → p ≥ 0.05，**不拒绝正态**
- 组 B：W = 0.8108，p = 0.0734 → p ≥ 0.05，**不拒绝正态**

**第 4 步：方差齐性（Levene，center = median）**

对 $Z_{ij} = |x_{ij} - \text{median}_i|$ 做单因素 ANOVA：

$$W = \frac{N-k}{k-1} \cdot \frac{\sum n_i(\bar{Z}_i - \bar{Z})^2}{\sum\sum(Z_{ij} - \bar{Z}_i)^2}$$

- W = 0.4737，p = 0.5070 → p ≥ 0.05，**方差齐** → 选用 Student's t（而非 Welch）

**第 5 步：独立样本 t 检验**

$$s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}, \quad t = \frac{\bar{x}_B - \bar{x}_A}{s_p \cdot \sqrt{1/n_1 + 1/n_2}}$$

- $s_p = \sqrt{(5 \times 0.013057 + 5 \times 0.019217) / 10} = \sqrt{0.016137} = \mathbf{0.1270}$
- $\text{SE} = 0.1270 \times \sqrt{1/6 + 1/6} = 0.1270 \times 0.5774 = \mathbf{0.0733}$
- $t = (5.1817 - 6.1683) / 0.0733 = -0.9867 / 0.0733 = \mathbf{-13.4532}$
- $df = n_1 + n_2 - 2 = \mathbf{10}$
- 双侧 $p = 2 \cdot P(T_{10} > |13.4532|) = \mathbf{9.903172 \times 10^{-8}}$

（scipy 复核：t = -13.4532，p = 9.903172e-08 —— 与手算一致）

**第 6 步：效应量 Hedges' g**

$$d = (\bar{x}_B - \bar{x}_A)/s_p = -0.9867 / 0.1270 = -7.7672$$

$$g = d \times \left(1 - \frac{3}{4(n_1+n_2)-9}\right) = -7.7672 \times \left(1 - \frac{3}{39}\right) = -7.7672 \times 0.9231 = \mathbf{-7.1697}$$

$|g| > 0.8$ 属大效应。

**第 7 步：Holm 多重比较校正**

该菌株的 family 含 8 个检验（2 个核心比较 × 4 个时间点）。把 8 个原始 p 升序排列，
第 i 小的乘以 (8 − i + 1)，再取累积最大值（保证单调），最后截断到 1：

| 排序 i | 比较 | 时间 | p_raw | 乘数 (8−i+1) | 乘数×p_raw | p_holm |
|---|---|---|---|---|---|---|
| 1 | 核心比较1 | 48h | 9.903e-08 | 8 | 7.923e-07 | 7.923e-07 |
| 2 | 核心比较1 | 24h | 2.058e-04 | 7 | 1.440e-03 | 1.440e-03 |
| 3 | 核心比较2 | 6h | 4.624e-03 | 6 | 2.775e-02 | 2.775e-02 |
| 4 | 核心比较1 | 72h | 4.698e-03 | 5 | 2.349e-02 | 2.775e-02 |
| 5 | 核心比较1 | 6h | 4.772e-03 | 4 | 1.909e-02 | 2.775e-02 |
| 6 | 核心比较2 | 24h | 8.158e-03 | 3 | 2.448e-02 | 2.775e-02 |
| 7 | 核心比较2 | 72h | 8.856e-03 | 2 | 1.771e-02 | 2.775e-02 |
| 8 | 核心比较2 | 48h | 1.068e-01 | 1 | 1.068e-01 | 1.068e-01 |

本例（核心比较1 / 48h）原始 p = 9.903e-08 在 8 个中排第 1 小，
校正后 $\mathbf{p_{\text{holm}} = 7.923 \times 10^{-7}}$，标记 `***`。

**结论**：48h 时，D1 的存在使 L43 的生物膜菌量从 6.17 降到 5.18 log CFU/cm²
（$\Delta = -0.99$），差异显著（Student's $t(10) = -13.45$，
$p_{\text{holm}} < 0.001$，Hedges' $g = -7.17$）。

## 5. 前提检查结果

32 个 series 中，**3 个**满足参数检验前提（采信 ANOVA/Tukey），
**29 个**不满足（采信 Kruskal-Wallis/Dunn）。逐 series 明细见
`stats_assumptions.csv`，逐 cell 的 Shapiro 见 `stats_assumptions_bycell.csv`。

按文件统计采信的方法：

| figure | nonparametric | parametric |
|---|---|---|
| fig1 | 8 | 0 |
| fig2 | 5 | 3 |
| fig3 | 8 | 0 |
| fig4 | 8 | 0 |

不满足前提的原因分布（逐 series 的具体 p 值见 `stats_assumptions.csv` 的 `reason` 列）：

| 原因 | series 数 |
|---|---|
| 仅方差不齐 | 17 |
| 残差非正态 + 方差不齐 | 9 |
| 仅残差非正态 | 3 |

**为什么绝大多数 series 落到非参？** 主因是 **Levene 方差不齐**，而非正态性 ——
生物膜计数的离散度随培养时间显著增大（6h 各复孔很接近，48/72h 明显分散），
把 12 个 cell 放在一起检验方差齐性自然容易被拒绝。这是数据的真实性质，不是错误。

需要说明的是：本设计**完全平衡**（12 个 cell 全部 n = 6），而平衡设计下的 ANOVA
对方差不齐相当稳健。因此本报告并不因为「判定为非参」就丢弃 ANOVA 结果 ——
两条路线都完整计算并输出，`primary_method` 列只标明按 rule.md 的规则应优先采信哪一条。

### 5.1 两条路线的结论一致性

取两条路线共有的比较（同一时间点下 `Single vs Dual`、`Dual vs Three`），
对照 Tukey HSD 与 Dunn(Holm) 在 α = 0.05 下是否给出相同的显著性判断。
理论上共 32 series × 4 时间点 × 2 对 = 256 个，其中 16 个因
「三组数值完全相同」而无法做 Dunn（检出限），实际可对照 **240 个**：

| 结论 | 比较数 |
|---|---|
| 两法都显著 | 83 |
| 两法都不显著 | 131 |
| 仅 Tukey 显著 | 10 |
| 仅 Dunn 显著 | 16 |

**一致率 89.2%**（214/240）。
分歧共 26 处（仅 Tukey 显著 10 处，
仅 Dunn 显著 16 处），集中在 p 值贴近 0.05 的边界情形。
换言之，**参数与非参的方法选择不改变本研究的实质结论**。

### 文字结论

以 4 log 接种量（fig2 / fig4，未受检出限干扰）为准：

**1. D1 与 D6 都抑制李斯特菌，但 D1 的抑制强得多。**
D1 使 4 株李斯特菌的生物膜菌量平均下降 **1.17 log**
（16/16 个时间点×菌株组合在 Holm 校正后显著，全部为下降）；
D6 的抑制幅度约为其一半，平均 **0.55 log**
（10/16 显著）。两者对 4 株李斯特菌的作用方向一致，无菌株特异性豁免。

**2. D1 在共培养中自身获益，D6 基本持平。**
与单菌相比，D1 在双菌体系下自身菌量平均上升 **+0.76 log**
（12/16 显著，全部为上升），说明 D1 与李斯特菌的关系接近
「单向竞争获胜」；D6 平均仅 **+0.11 log**（7/16 显著，方向不一），
更接近中性共存。

**3. 加入第三个菌会削弱对李斯特菌的抑制，且这一效应主要由 D6 带来。**
在 D1-L 基础上加入 **D6**（fig2 → 三菌），李斯特菌回升 **+0.85 log**
（15/16 显著，全部为上升），同时 D1 自身被压低 **-0.38 log**
（5/16 显著）。
反过来，在 D6-L 基础上加入 **D1**（fig4 → 三菌），李斯特菌只回升 **+0.24 log**
（4/16 显著），D6 自身下降 **-0.39 log**。

综合看：**D6 与 D1 之间存在竞争**，D6 的存在削弱了 D1 对李斯特菌的抑制作用 ——
从食品安全角度，三菌共存的生物膜对李斯特菌的抑制效果不如 D1 单独与之共培养。

**4. 接种量决定了能否观察到效应。** 2 log 接种（fig1/fig3）下，李斯特菌读数大量落在检出限，
fig3 甚至没有任何一个核心比较 1 达到显著。这不代表 D6 在低接种量下没有抑制作用，
而是**该实验条件下无法分辨** —— 结论应以 4 log 组为准。

## 8. 局限性

1. **D 菌的单菌基线被重复使用。** 每份文件只有一组 D 菌单菌数据（6 复孔），
   但它同时充当了 4 个 partner series（L43/L1091/L1253/L2182）的对照。
   因此针对 D 菌的这 4 次分析**并非相互独立**，其 Holm 校正只在各自 family 内进行，
   跨 partner 的整体族系错误率未被控制。解读 D 菌结果时应把 4 个 partner 视为一体。

2. **检出限左删失严重削弱功效。** fig1 与 fig3（2 log 接种量）中，L 菌在 6h、部分 24h
   的读数被压在检出限（多个 cell 全为 1.0）。这类数据的方差被人为归零，
   任何检验都不可靠；表中相应位置记为 `—` 或 `identical_no_variation`。
   若要在低接种量下得到可靠结论，需要更灵敏的计数方法或明确的删失模型。

3. **疑似录入重复使有效 n 可能为 3。** 见第 2 节 (c)，涉及 3 组
   （均为 fig1 的 D1 在 24h）。若这 3 组实为 3 次重复，其标准差被低估、p 值被高估。

4. **n = 6 时 Shapiro-Wilk 功效很低。** 单个 cell 的正态性检验几乎不可能拒绝原假设，
   所以本报告以 72 个残差的 Shapiro 作为主判据，cell 级结果仅供参考。

5. **无法区分「直接作用」与「间接释放」。** 数据中缺少 `D1-D6`（不含 L 菌）的双菌对照，
   因此当三菌体系里李斯特菌回升时，无法判断这是 D6 对李斯特菌有直接促进作用，
   还是 D6 压制了 D1、从而间接解除了 D1 对李斯特菌的抑制。
   第 7 节观察到「加入 D6 时 D1 自身下降 $-0.38$ log、李斯特菌回升 $+0.85$ log」，
   与后一种解释更吻合，但现有数据不足以定论。若要拆开，需要补 `D1-D6` 组合。
